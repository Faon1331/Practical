# Веб-сервис: характеристики заведения по тексту отзыва

Небольшой сервис на FastAPI поверх итоговой модели из `pipeline/`
(TF-IDF по словам и биграммам + логистическая регрессия с весами классов
и своим порогом для каждой метки). По тексту отзыва он возвращает, какие
из 19 характеристик подходят заведению, с вероятностями и порогами.

## Структура

```
backend/
  app/
    main.py      - API (маршруты)
    config.py    - пути; метки и предобработка берутся из pipeline/common.py
    model.py     - загрузка итоговой модели и предсказание
    schemas.py   - форматы запросов и ответов
    static/      - демо-страница
  tests/         - тесты API
```

## Запуск

Сначала нужно прогнать скрипты `pipeline/01 ... 16` (см. README в корне):
сервису нужен файл `models/final_model.joblib`. Потом из папки `backend`:

```bash
uvicorn app.main:app --port 8000
```

Демо-страница: http://localhost:8000, описание API: http://localhost:8000/docs

Тесты: `pytest`

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/health` | состояние сервиса |
| GET | `/api/labels` | список характеристик и групп |
| POST | `/api/predict` | `{"text": "..."}` -> характеристики, вероятности и пороги |
| POST | `/api/predict/batch` | `{"texts": [...]}`, до 100 отзывов за раз |

Пример ответа `/api/predict`:

```json
{
  "labels": ["Расслабиться", "Свидание"],
  "scores": [
    {"label": "Расслабиться", "group": "Цель визита", "probability": 0.99, "threshold": 0.5, "predicted": true},
    ...
  ]
}
```
